# odin-recipes

This is my first HTML project as part of [The Odin Project](https://www.theodinproject.com/) Foundations curriculum. It is a simple recipe website featuring a main index page linking to three traditional Austrian recipes: Wiener Schnitzel, Kürbiscremesuppe, and Kaiserschmarrn.

## Skills Demonstrated

- Setting up a basic HTML boilerplate structure
- Structuring content with headings (`<h1>`, `<h2>`, `<h3>`) and paragraphs (`<p>`)
- Creating unordered (`<ul>`) and ordered (`<ol>`) lists for ingredients and preparation steps
- Linking multiple pages using relative paths (`<a>`) and embedding images (`<img>`)
- Using Git and GitHub for version control, writing structured commit messages, and deploying via GitHub Pages
